## Agent skills

### Issue tracker

Issues and specs live in local Markdown files under `.scratch/<feature>/`. Before tracker operations, read `docs/agents/issue-tracker.md`.

### Triage labels

Local issue statuses use the five default triage roles. Before applying a triage status, read `docs/agents/triage-labels.md`.

### Domain docs

Domain docs use a single-context layout: root `GLOSSARY.md` and `docs/adr/`. Before exploring the codebase, read `docs/agents/domain.md`.

# Triage Labels

The engineering skills use five canonical triage roles. This file maps them to this repo's local tracker vocabulary, recorded in each issue's `Status:` line.

| Canonical role | Local tracker value | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a triage role, use the corresponding local tracker value from this table.

Edit the "Local tracker value" column to change the vocabulary.
